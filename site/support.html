1. 当前版本支持

  • 语音录入

3. 语言与语音识别

界面当前支持简体中文、繁体中文、English、Español 和日本語。

语音识别语言可独立选择跟随 App、`zh-CN`、`zh-TW`、`en-US`、`es-US`、`es-MX`、`es-ES` 或 `ja-JP`。

当前版本中，中文、英文、西班牙语和日语都可用于语音输入。中文、西班牙语和日语支持常用提醒时间、重复规则、物品位置记录与自然语言位置搜索；英文支持语音/文字笔记和关键词搜索。

4. 常见问题

为什么语音没有反应？

  • 请确认已允许麦克风权限
  • 请确认已允许语音识别权限
  • 请优先在真机上测试

如需重新授权，请打开 iPhone“设置”，找到 “Mind Talk”，开启麦克风、语音识别和通知权限。

为什么提醒没有弹出？

  • 请确认已允许通知权限
  • 请确认提醒时间设置在未来
  • 请确认 iPhone 已允许 Mind Talk 发送系统通知

可新建一条 2 到 3 分钟后的提醒并锁屏等待，用真实提醒验证本地通知链路。

为什么日历没有天气？

日历天气需要“使用 App 时”定位权限和可用网络。拒绝定位只会关闭天气提示，不影响记录、搜索、提醒或备份。可到 iPhone“设置”中重新授权后返回日历刷新。

备份文件如何使用？

  • 在“设置”页点击“生成备份文件”导出当前本地数据
  • 如需更换设备或删除 App，建议先把备份文件保存到“文件”App 或 iCloud Drive
  • 点击“导入备份文件”恢复之前导出的 JSON 文件

导入会覆盖当前本地记录和提醒，导入后应用会重新同步本地通知。

数据会上传到开发者服务器吗？

当前版本不提供账号系统或开发者自建云同步，也不把你的记录正文、提醒内容或搜索历史上传到开发者服务器。记录默认保存在本机；只有在你主动导出备份后，文件才会保存到你选择的位置。

English

1. Features in the Current Version

  • Text input
  • Voice input
  • Storage and location records
  • Reminder records
  • General notes
  • Local search
  • Local reminder notifications
  • Optional calendar weather with location permission
  • Local backup export and import with manual transfer through Files or iCloud Drive

2. Current Limitations

  • No account system, group sharing, subscription, or paid upgrade
  • No automatic cloud sync in the current release; use manual backup export and import across devices

3. Interface and Speech Languages

The interface currently supports English, Simplified Chinese, Traditional Chinese, Spanish, and Japanese.

Speech recognition can follow the app language or be set independently to `zh-CN`, `zh-TW`, `en-US`, `es-US`, `es-MX`, `es-ES`, or `ja-JP`.

In the current release, Chinese, English, Spanish, and Japanese can all be used for voice input. Chinese, Spanish, and Japanese support common reminder schedules, repeat rules, item-location capture, and natural-language location search. English supports voice and text notes plus keyword search.

4. Frequently Asked Questions

Why does voice input not start?

  • Check that microphone permission is enabled
  • Check that speech recognition permission is enabled
  • Test on a real iPhone first

To re-enable permissions, open iPhone Settings, find Mind Talk, and enable microphone, speech recognition, and notifications.

Why did my reminder not appear?

  • Check that notification permission is enabled
  • Make sure the reminder time is in the future
  • Make sure iPhone notifications are allowed for Mind Talk

Create a reminder 2 to 3 minutes in the future and lock the iPhone to verify local notification delivery.

Why is weather missing from the calendar?

Calendar weather requires When In Use location permission and a working network connection. Denying location disables only weather; capture, search, reminders, and backups remain available. You can re-enable location in iPhone Settings and refresh the calendar.

How do backups work?

  • Use “Generate Backup File” in Settings to export local data
  • Save the file to Files or iCloud Drive before deleting the app or moving data to another device
  • Use “Import Backup File” to restore a previously exported JSON backup

Importing replaces current local records and reminders, and local notifications are re-synced after import.

Does the app upload my data to a developer server?

The current release does not include account registration or developer-operated cloud sync, and does not send your record content, reminder content, or search history to a developer server. Records stay on your device unless you explicitly export a backup.
