# Mind Talk 隐私政策草案

生效日期：2026 年 8 月 6 日

本草案基于当前 `美区本地版 MVP` 的真实能力撰写，适用于首发阶段的 Mind Talk iOS 应用。

---

## 中文版

### 1. 我们是谁

Mind Talk 是一款面向个人生活场景的本地优先记录应用，用于帮助用户记录物品位置、提醒事项和临时笔记。

### 2. 应用处理与存储的信息

在当前版本中，Mind Talk 不要求你创建账号，也不主动向开发者服务器上传你的个人记录内容。

应用本地可能保存以下信息：

- 你手动输入的记录内容
- 你通过语音转写后确认保存的记录内容
- 你创建的提醒事项与提醒时间
- 最近搜索历史
- 你手动导出的本地备份文件内容

这些信息保存在你的设备本地。当前首发版本不提供自动云同步；只有当你主动导出备份时，应用才会生成 JSON 文件，并由你决定是否保存到“文件”、iCloud Drive 或其他位置。

### 3. 语音与麦克风权限

当你使用语音录入功能时，Mind Talk 会请求：

- 麦克风权限
- 语音识别权限

这些权限仅用于将你的语音转换为文字并填入应用内的录入内容。

Mind Talk 当前版本不提供开发者自建语音服务器，不会主动把你的语音录音上传到开发者控制的后端。
但 iOS 系统语音识别能力可能由 Apple 提供或处理，你对该功能的使用也会受到 Apple 自身隐私政策和系统行为的约束。

### 4. 定位与天气

当你主动获取日历天气时，Mind Talk 会请求“使用 App 时”定位权限，并使用约 3 公里精度的位置向 Apple WeatherKit 请求未来天气。定位只用于本次天气请求，不写入 Mind Talk 的记录、备份或 Release 日志。拒绝定位不会影响记录、搜索、提醒或备份。

### 5. 通知权限

当你使用提醒功能时，Mind Talk 会请求通知权限，用于在提醒时间到达时，通过 iPhone 的本地通知向你发送提醒。

当前版本使用的是本地通知，不依赖开发者服务器推送。

### 6. 文件访问与本地备份

当你导入备份文件时，Mind Talk 会通过系统文件选择器访问你主动选中的 JSON 文件。
当你导出备份文件时，Mind Talk 会在系统提供的分享与存储流程中生成备份文件。

Mind Talk 不会在未获得你主动操作的情况下，浏览或读取你的其他文件。

### 7. 数据共享

当前版本中，Mind Talk：

- 不提供账号系统
- 不提供自动云同步
- 不提供群组共享
- 不提供广告 SDK
- 不提供第三方营销跟踪
- 不向开发者服务器发送你的记录正文、提醒内容或搜索历史

### 8. 数据保留与删除

你的记录、提醒和搜索历史默认保留在你的设备本地，直到你：

- 在应用内手动删除
- 用导入备份覆盖当前数据
- 卸载应用

如果你导出了备份文件，该备份文件的保存、删除和转移由你自己控制。

### 9. 儿童隐私

当前版本不面向儿童进行定向画像、广告投放或社交运营。  
如果你是监护人，并认为未成年人在未经允许的情况下使用了本应用，请通过支持渠道联系开发者。

### 10. 政策更新

如果 Mind Talk 未来引入账号、家庭 group、服务器接口或第三方服务，本隐私政策将同步更新。

## English Version

### 1. Who We Are

Mind Talk is a local-first personal memory app designed to help users save everyday information such as where items are stored, what reminders they need, and quick notes.

### 2. Information the App Processes and Stores

In the current version, Mind Talk does not require account registration and does not actively upload your personal records to a developer-operated server.

The app may store the following information locally on your device:

- Text that you manually enter
- Text saved after voice transcription
- Reminder titles, times, and statuses
- Recent search history
- Backup data that you choose to export manually

This information is stored on your device. The current release does not provide automatic cloud sync. A JSON file is created only when you explicitly export a backup, and you choose whether to save it to Files, iCloud Drive, or another destination.

### 3. Microphone and Speech Recognition Permissions

When you use voice input, Mind Talk may request:

- Microphone permission
- Speech recognition permission

These permissions are used only to convert your speech into text inside the app.

Mind Talk does not currently operate its own speech-processing backend and does not intentionally upload your audio recordings to a developer-controlled server.
However, iOS speech recognition may rely on Apple-provided services or system processing, and your use of that functionality is also subject to Apple's own privacy policies and system behavior.

### 4. Location and Weather

When you request calendar weather, Mind Talk asks for When In Use location permission and uses a location with approximately three-kilometer accuracy to request forecast data from Apple WeatherKit. Location is used only for the weather request and is not written to Mind Talk records, backups, or Release logs. Denying location does not affect capture, search, reminders, or backups.

### 5. Notification Permission

When you use reminders, Mind Talk may request notification permission so your iPhone can deliver local reminder notifications at the scheduled time.

The current version uses local notifications and does not rely on developer server push delivery.

### 6. File Access and Local Backups

If you import a backup, Mind Talk accesses only the JSON file that you explicitly choose through the system file picker.
If you export a backup, Mind Talk creates a backup file through the standard iOS share and save flow, which may include saving the file to Files or iCloud Drive if you choose.

Mind Talk does not browse or read unrelated files on your device without your direct action.

### 7. Data Sharing

In the current version, Mind Talk:

- does not provide account registration
- does not provide automatic cloud sync
- does not provide group sharing
- does not include advertising SDKs
- does not include third-party marketing trackers
- does not send your record text, reminder text, or search history to a developer-operated backend

### 8. Data Retention and Deletion

Your data remains on your device until you:

- delete it manually inside the app
- overwrite it by importing a backup
- remove the app from your device

If you export a backup file, storage and deletion of that file are under your control.

### 9. Children's Privacy

The current version is not designed for profiling children, targeted advertising, or social interaction.  
If you are a parent or guardian and believe a minor used the app inappropriately, please contact the developer through the support channel.

### 10. Policy Updates

If Mind Talk later introduces accounts, family groups, server-side services, or third-party integrations, this Privacy Policy will be updated accordingly.
