## 开发环境说明

- iOS Deployment Target：iOS 16.0
- Swift：6.0
- 本地 Swift Package：`YijiCore`
- 工程当前保留原开发者的 Bundle ID 和 Development Team。朋友在自己的电脑编译或真机安装时，需要在 Xcode 的 Signing & Capabilities 中换成自己的开发者账号或团队。
- 本次交付已执行 Swift 语法解析和 Xcode 工程结构检查。
- 制作交付包的电脑未安装完整 Xcode，Command Line Tools 与 SDK 小版本不一致，因此未执行最终模拟器构建；接手后请先在完整 Xcode 中 Build 一次。

## 数据兼容

旧版备份没有 `expenses` 或 `expenseCategories` 字段时，会自动读取为空帐本和默认类别，不影响原有记录、提醒和搜索历史。

新版本导出的备份包含记账数据。导入备份会覆盖当前本地数据，测试导入前请先导出一份现有备份。
