## 可直接粘贴的英文 Review Notes

```text
This app does not require account creation or sign-in. All core features are available without a username or password.

Core review path:
1. Open the first tab and test voice or text capture.
2. Save a regular note such as “The spare key is in the desk drawer”, then use Search to find it.
3. To review Chinese reminder parsing, enter “明天下午三点提醒我交物业费” and save it.
4. Open Calendar to review saved records by date.
5. Open Settings to review app language, speech recognition language, permission status, support links, and backup options.

Permissions:
- Microphone + Speech Recognition: required only for voice capture
- Notifications: required only for reminder delivery
- Location While Using the App: optional, used only for calendar weather

If these permissions are denied, text capture, local record storage, search, and manual JSON backup still work.

The app uses local-first storage, local notifications, optional Apple WeatherKit forecasts, and manual JSON backup export/import. It does not require an account, a developer-operated backend, or automatic cloud sync.
```
